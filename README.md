# Furniture Shop (Back-end)

Furniture Shop is a full-featured e-commerce web application for selling furniture, developed using Python and Django.

I was responsible for implementing the back-end logic of the application, including business processes, database interaction, and handling client requests, simulating real commercial development experience.

## Tech Stack:
Python
Django
PostgreSQL
AJAX

## Key Features:
Product management system (create, update, retrieve products)
Dynamic shopping cart powered by AJAX (no page reloads)
Order processing and persistence in the database
User authentication and authorization
Personal user account (profile management, order history)
Efficient interaction with PostgreSQL database

## Highlights:

Designed and implemented core business logic of an e-commerce platform
Improved user experience with a dynamic, responsive cart system
Built a structured and scalable back-end following Django best practices
Worked with real-world scenarios such as checkout flow, cart calculations, and user data handling
